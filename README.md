# MoneyMate 💰

MoneyMate is a comprehensive Java-based web application designed to help students and their parents track, manage, and understand their finances. Built with Java Servlets, JSP, JDBC, and Oracle Database, it offers a robust platform for expense tracking, investment management, and financial oversight.

## 🚀 Features

- **Student Dashboard**: A personalized space for students to log expenses, track allowances, and view their financial history.
- **Parental Portal**: Allows parents to monitor their child's spending habits, allocate allowances, and ensure financial responsibility.
- **Expense Tracking**: Easily log day-to-day expenses categorized for better insights.
- **Investment Management**: Features to track simple savings and investments over time.
- **Secure Access**: Role-based login system separating Student and Parent functionalities.

## 🛠️ Technology Stack

- **Backend**: Java, Servlets, JSP (JavaServer Pages)
- **Database**: Oracle Database XE
- **Web Server**: GlassFish Server (4.1.1 or compatible)
- **IDE**: NetBeans (recommended for setup and running)
- **Frontend**: HTML, CSS (JSP integration)
